# Phase 09 physical evidence

Store only bounded text or JSON evidence here. Each record must include the
timestamp, host, node ID, non-secret configuration fingerprint, scenario,
observed result, latency when measured, recovery notes, and an honest
`PASS`/`PARTIAL`/`DEFERRED` status.

Do not store passwords, tokens, private keys, raw audio, sensitive screen
content, model blobs, or test artifacts.
