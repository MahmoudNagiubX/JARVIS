# Daily Routines

The personal operation catalog is orchestration over existing services, not
a new task engine. It supports work start, study start, focus start/end,
project/system checks, end-of-day, weekly review, leave, return, and sleep
modes. Built-in home templates compile to safe `HomeActionService` calls.

Operations remain usable offline when their local authorities are available.
Network-dependent adapters remain explicitly unavailable and are reported in
the structured step result.
