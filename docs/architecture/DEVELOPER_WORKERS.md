# Developer workers

`DeveloperWorkerGateway` may report the safe local `codex` candidate without
installing or launching it. Google-account-backed CLI candidates are excluded
from discovery. If a future deployment injects an executor, it must retain
workspace scope, timeout, and the existing worker/audit/event path.

OpenClaw is a reserved adapter seam only. The local OpenClaw donor was audited
read-only; no gateway, channel, model, or tool code was copied and no direct
shell route was added. The core remains the single JARVIS authority.
