# Developer workers

`DeveloperWorkerGateway` detects installed `codex`, `gemini`, and
`antigravity` executables without installing, launching, or configuring them.
Unavailable tools are represented as unavailable capabilities. If a future
deployment injects an executor, it must retain workspace scope, timeout, and
the existing worker/audit/event path.

OpenClaw is a reserved adapter seam only. The local OpenClaw donor was audited
read-only; no gateway, channel, model, or tool code was copied and no direct
shell route was added. The core remains the single JARVIS authority.
